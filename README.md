# Proyek 87: Game Tebak Warna Hex Code (Hex Code Guessing Game)

Proyek ini adalah permainan edukatif berbasis web untuk melatih pemahaman visual terhadap format kode warna Hexadecimal (`#RRGGBB`). Pemain diminta menebak kode Hex yang sesuai dengan warna yang ditampilkan pada kotak pratinjau. Dibuat menggunakan **HTML5, CSS3, dan Vanilla JavaScript**, cocok sebagai contoh proyek mini-game sederhana bagi siswa SMK/pemula.
